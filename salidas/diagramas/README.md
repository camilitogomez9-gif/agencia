# Diagramas

Diagramas draw.io generados por el comando `/diagramar`.

Cada archivo `.drawio` es XML nativo importable directamente en draw.io o app.diagrams.net.

## Convención de Nombres

```
YYYY-MM-DD-{tipo}-{tema-corto}.drawio
```

**Tipos:** `ventas`, `youtube`, `proceso`, `generico`

**Ejemplo:** `2026-03-06-ventas-la agencia-discovery.drawio`

## Cómo Abrir

- **draw.io desktop:** Archivo → Abrir → seleccionar el archivo
- **draw.io web:** Ir a [app.diagrams.net](https://app.diagrams.net) → arrastrar el archivo
- **Importar en diagrama existente:** Extras → Editar Diagrama → pegar el XML
