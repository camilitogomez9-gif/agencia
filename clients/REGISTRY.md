# Client ID Registry

Registro de identificadores de cliente. Cada ID es un código único de 3 letras mayúsculas.

**Antes de crear un cliente nuevo:** verificar que el ID no esté en esta lista.
**Al crear un cliente nuevo:** agregar una fila a esta tabla.
